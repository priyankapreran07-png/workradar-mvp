# WorkRadar MVP - by Priyanka S

**Live Demo:** https://warm-begonia-bcb307.netlify.app
**GitHub Repo:** https://github.com/priyankapreran07-png/workradar-mvp

## What is this?
Project radar AI brief - Team work made clear. Dashboard with 5 open / 2 urgent / 1 blocked, AI Daily Brief, Priority feed.

## How to run - No install needed
1. Click green Code button -> Download ZIP
2. Unzip file
3. Double-click index.html -> Opens in browser, works offline

## Features Included
- Dashboard with team overview
- Priority feed with Assign / Done / Snooze
- Search by title/owner/source
- AI Daily Brief sample summary
- Empty / error state handling

Built with single HTML file - sample data, no live integrations.
